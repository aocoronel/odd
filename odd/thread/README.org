* Thread

This provides yet another thread pool.

Inspired by:

- Odin's thread_pool.odin
- https://aocoronel.github.io/multicore
- https://github.com/aocoronel/aoclibs/blob/main/src/thread.c
- https://www.dgtlgrove.com/p/multi-core-by-default

** Features

- Enqueue tasks from any thread, to any pool.
- Tasks are executed by all threads, not just one.
- Provides ~range~ for lock-free iterations.
- Provides ~next_static~ and ~next_dynamic~ for lock-free iterations with work-stealing.
- Set a custom thread ~runner~.
- Assertion procedure doesn't exit, letting main thread cleanup
- That's pretty much it. Simplicity is also a feature.

Making a universal library that can beautifully handle all use cases is impossible, or would be extensibly complicated. For example, I've been working on a ~wait~ procedure that can perfeclty wait on all pools, and tell when they are done, but if there is a pool that is independent and can add tasks at any time, it requires a different approach, possibly at the user level.

This API tries to be both simple and extensible. Many convenience procedures are available at [[./easy]], but you can use the parts to make your own high level API, accordingly to your specific cases.

** Take a taste

#+BEGIN_SRC odin
  // A small wrapper to rc_thread, for type safety
  rc :: proc(pool: ^thread.Pool, files: []os.File_Info, allocator := context.temp_allocator) {
  	context.allocator = allocator
  	files_ptr := new([]os.File_Info)
  	files_ptr^ = files
  	thread.add_task(pool, rc_thread, files_ptr, new(int))
  }

  // Print all files in directory, recursively
  rc_thread :: proc(t: ^thread.Task) {
  	files := cast(^[]os.File_Info)t.data[0]
  	tasks := cast(^int)t.data[1]

  	for i in thread.next(tasks, len(files)) {
          f := files[i]
  		if f.type == .Directory {
  			fs, err := os.read_directory_by_path(f.fullpath, -1, context.temp_allocator)
  			if err != nil {
  				log.errorf("t[%d]: %s: %s", thread.current_thread_id, f.fullpath, os.error_string(err))
  				continue
  			}
  			rc(thread.context_pool, fs)
  		} else {
  			fmt.println(f.fullpath)
  		}
  	}
  }
#+END_SRC
