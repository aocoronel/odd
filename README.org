* odd

A very odd collection from scratch in Odin, implementing odd ideas, or reinventing what Odin already did in it's collections.

#+BEGIN_QUOTE
This project is the continuation of the unmaintained [[https://codeberg.org/aocoronel/aoclibs][aocoronel/aoclibs]], that did the same thing, but in the C programming language.
#+END_QUOTE

** Highlights

- ~debug~: backtrace on relevant signals.
- ~encoding/csv.odin~: dead simple CSV parser.
- ~encoding/tokenizer~: simple tokenizer, that supports text, integers and comma.
- ~flags~: reimagination of ~odin/flags~, based on ~aocoronel/aoclibs~ Crown library.
- ~mem/c.odin~: forbidden C techniques.
- ~os/pipe.odin~: thin wrapper for ~os.process_exec~ and ~os.process_start~.
- ~terminal/terminal_size.odin~: cross-platform terminal size.
- ~thread~: thread pool inspired by [[https://www.dgtlgrove.com/p/multi-core-by-default][Multicore by default]].

** Running examples

#+BEGIN_SRC bash
odin run examples -collection:shared=.
#+END_SRC
