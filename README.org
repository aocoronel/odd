* odd

A very odd collection of libraries from scratch in Odin. This project is the continuation of the archived [[https://codeberg.org/aocoronel/aoclibs][aoclibs]], that did the same thing, but in the C programming language.

#+BEGIN_QUOTE
Compared to aoclibs, this has way less code, because Odin implements almost everything I did in there, and with much better API
#+END_QUOTE

** Highlights

- ~odd/debug~: backtrace on SIGSEGV.
- ~odd/encoding~: supports parsing: CSV.
- ~odd/flags~: reimagination of ~odin/flags~, based on ~aocoronel/aoclibs~ Crown library.
- ~odd/pipe~: thin wrapper for ~os.process_exec~ and ~os.process_start~.
- ~odd/term~: cross-platform terminal size.
- ~odd/thread~: thread-safe allocator on the [[https://www.dgtlgrove.com/p/multi-core-by-default][Multicore by default]] style.
- ~odd/tokenizer~: simple tokenizer, that supports text, integers and comma.

** Running examples

#+BEGIN_SRC bash
odin run examples -collection:shared=.
#+END_SRC
